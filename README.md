# Weather App 🌤️

A responsive weather application built using HTML, CSS and JavaScript.

The application uses the Open-Meteo API to retrieve real-time weather information and weather forecasts.

## Features

- Search weather by city
- Current temperature
- Feels-like temperature
- Humidity
- Wind speed
- Atmospheric pressure
- Visibility
- Sunrise and sunset
- 5-day weather forecast
- Celsius / Fahrenheit conversion
- Current location weather
- Recent searches
- Dynamic weather-based backgrounds
- Responsive design
- Error handling
- Loading states

## Technologies Used

- HTML5
- CSS3
- JavaScript
- REST APIs
- Open-Meteo API
- Browser Geolocation API
- Local Storage
